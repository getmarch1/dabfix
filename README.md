# DAB Fix for Harman MHI2 Units

**Source:** Digital Eliteboard – *Kostenloses DABFix für Harman MHI2 Modelle*

## Compatibility

This fix is intended **only for Harman MHI2 units equipped with DAB**.

## Installation Instructions

1. Prepare an SD card formatted as **FAT32**.
2. Copy `metainfo2.txt` and all required subfolders to the **root directory** of the SD card.
3. Insert the SD card into **SD Slot 1**.
4. Open the **Red Engineering Menu**.
5. Start the update process.
6. Follow the on-screen instructions until the process is complete.

## Requirements

- FAT32-formatted SD card
- `metainfo2.txt`
- All required subfolders and update files
- Compatible Harman MHI2 DAB unit

## Disclaimer

Use this procedure only with compatible units. Proceed at your own risk and ensure that all update files are correct for your specific device.

Incorrect or incompatible update files may cause malfunctions or render the infotainment system unusable.
